# 勞報單填寫工具

在別人給的 PDF 上填字、蓋簽名、貼身分證，然後存成新的 PDF。

一個 HTML 檔，雙擊就開。不用安裝、不用註冊、不連網路、不用付錢。

---

## 這是為了解決什麼

接案的人每個月都要填廠商寄來的勞務報酬單。每家格式都不一樣，於是每一份都要重打一次同樣的姓名、身分證字號、地址、銀行帳號，簽名檔和身分證影本還要重新找、重新縮放對齊。

macOS 內建的「預覽程式」可以在 PDF 上加文字和簽名，**如果你一年只填兩三次，用它就夠了**。但它不記憶任何資料，也不能直接拖圖片檔進去。

這個工具就是為了「重複填很多份」而做的：資料存一次，之後每份 PDF 都是「點一下 → 打字」。

## 怎麼用

下載 `勞報單填寫工具.html`，雙擊開啟。

1. 把 PDF 拖進畫面中間
2. **在要填的位置點一下，直接打字**
3. 打完接著點下一格，不用按什麼結束
4. 按右上角「輸出 PDF」

點錯地方沒關係，空的文字框會自己消失。

> **建議用 Chrome 開。** 如果雙擊後看到的是一堆程式碼，表示你的系統把 `.html` 的預設程式設成了編輯器——在檔案上按右鍵 →「打開檔案的應用程式」→ Chrome。

### 快捷鍵

| 動作 | 按鍵 |
|---|---|
| 改字 | 在文字上**雙擊**（整段選起來，直接打就取代） |
| 刪掉選中的 | `Delete` |
| 微調位置 | 方向鍵 |
| 大步移動 | `Shift` + 方向鍵 |
| 結束打字／取消 | `Esc` |
| 換行 | 打字時按 `Enter` |

### 常用資料（選用）

左邊那排欄位是給懶得重打的東西用的——姓名、身分證字號、地址、銀行帳號。
填一次會自己記住，之後點「放上去」再點位置，省一次輸入。欄位可以自己增刪改名。

不想用就空著，完全不影響直接在 PDF 上打字。

### 簽名和身分證

先用「加入圖片」把檔案存起來（存一次就好），之後每次點「放上去」再點位置。
大小用浮動工具列的 ＋／− 調，**它會記住你調過的尺寸**，下次放上去就是同樣大小。

手機拍的身分證通常有四千像素，會自動縮到 1800px 再存（印出來遠超所需）。
有透明背景的簽名檔維持 PNG，照片則轉成 JPEG。

## 隱私

**所有資料只存在你自己的瀏覽器裡，不會上傳到任何地方。** 這個工具沒有伺服器，也沒有任何對外連線。

代價是：清除瀏覽器資料會把存的東西一起清掉，換瀏覽器或換電腦也要重新輸入。

身分證影本只在你輸出的 PDF 裡才會出現——寄出去前記得確認收件人。

## 它是怎麼運作的

**原始 PDF 完全不動，填的內容疊成一層蓋上去。**

所以廠商表單裡原本的文字、格線、條文全部原封不動保留，對方仍然可以搜尋和複製原文。輸出的檔案也幾乎不會變大（實測 225 KB 的表單填完是 253 KB）。

這麼做還有一個好處：不需要在 PDF 裡嵌入中文字型。字型子集化在中日韓字型上很容易出錯——四萬多個字形，工具一失手就整排掉字。疊圖層讓這個問題完全消失，而且畫面看到什麼，輸出就一定是什麼。

代價是**輸出後不能再回頭編輯**。想改的話重開原始 PDF 重填即可，你存的資料和圖片都還在。

## 它不做什麼

**改掉 PDF 上原本已經印好的字**（例如廠商把金額打錯了）。

這需要解析 PDF 的內容流、重新嵌入字型、重排版面——瀏覽器裡做不出堪用的結果，這也正是那些 PDF 編輯器要收費的原因。

要做這件事，裝 [LibreOffice Draw](https://www.libreoffice.org/)（免費開源）：直接用它開 PDF，原本的文字會變成可以點選修改的文字框。簡單表單改個金額、日期沒問題；排版複雜的檔案可能會跑版，改完記得檢查。

## 開發

```
勞報單填寫工具.html   打包後的成品，就是這一個檔案

index.html          介面
style.css           樣式
app.js              全部邏輯
lib/                pdf.js（讀 PDF）、pdf-lib（寫 PDF）
build.mjs           把上面幾個打包成單一 HTML
啟動.command        開發時用，起一個本機伺服器
```

改完 `app.js` 或 `style.css` 之後重新打包：

```bash
node build.mjs
```

之所以要打包，是因為 `file://` 底下瀏覽器會擋掉 ES module 載入和 Web Worker。打包時把 pdf.js 的 worker 包成 blob URL，雙擊開啟才能正常運作。
